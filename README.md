🧠 Quiz Game Using Python
📌 Project Description

The Quiz Game is a simple interactive Python-based application that asks multiple-choice questions and allows users to test their knowledge.

The user answers each question by selecting an option (A, B, C, or D). The program validates the input, checks the answer, and updates the score accordingly.

At the end of the quiz, the application displays the total score, percentage, and performance message.

🎯 Objectives
Understand Python loops and conditional statements.
Learn how to handle user input.
Practice storing and managing data using lists and dictionaries.
Implement answer validation.
Learn how to calculate and display scores.
Improve logical thinking and problem-solving skills.
🛠️ Technologies Used
Programming Language: Python
Concepts: Lists, Dictionaries, Loops, Conditional Statements, User Input
✨ Features
Multiple-choice quiz questions.
Four options for each question.
Validates user input (A/B/C/D).
Checks answers automatically.
Tracks the user's score.
Displays the correct answer for incorrect responses.
Calculates the final percentage.
Displays a performance message based on the score.
